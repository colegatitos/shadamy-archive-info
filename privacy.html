Privacy Policy

Last updated: October 12, 2026

Shadamy Archive is a personal image-collection project. It is not offered as a service to other users.

Google Drive access

The collector requests the drive.file permission to create and manage its own archive files and folders in the owner's Google Drive. It does not request access to all existing Drive files, Gmail, or Google Contacts.

Information stored

The private archive stores publicly accessible images, posting-account names, source links, available captions and tags, dates, image hashes, and collection progress.

Processing and credentials

The collector runs in GitHub Actions. Google authorization credentials are stored in private GitHub Actions secrets. Downloaded images are temporarily processed on GitHub's runners before being uploaded to Google Drive.

Use and sharing

The project does not sell archive information, use Google user data for advertising, or use Google user data to train AI models. The archive is not intentionally published or shared with other users. Google and GitHub process data as needed to provide their respective services.

Retention and deletion

Archive files are retained until the owner deletes them. The owner can stop collection by disabling the GitHub workflow, revoke authorization through Google Account settings, and delete archive files from Drive.

This website

This information website has no added analytics, advertising, or forms. GitHub Pages may collect technical information under GitHub's own privacy policy.
